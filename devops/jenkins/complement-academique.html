Complément académique — Jenkins

Automatisation CI/CD, pipelines déclaratifs et gouvernance.

1. Rôle de Jenkins

Jenkins automatise l'exécution de tâches du cycle de développement : récupération du code, compilation, tests, génération d'artefacts et déploiement. Sa valeur réside dans l'orchestration reproductible de ces étapes.

2. Pipeline

Checkout → Build → Test → Package → Deploy → Verification.

Un Jenkinsfile versionné permet de conserver la définition du pipeline avec le projet et d'améliorer la traçabilité.

3. Qualité et observabilité

Chaque étape doit produire un résultat vérifiable. Les logs, artefacts, statuts de tests et durées d'exécution facilitent l'analyse des échecs. Les pipelines doivent également échouer rapidement lorsqu'une condition essentielle n'est pas satisfaite.

4. Sécurité

  • Stocker les secrets dans le gestionnaire de credentials.
  • Limiter les permissions des agents.
  • Maintenir les plugins et le serveur.
  • Éviter les scripts non contrôlés.
  • Isoler les agents selon le niveau de confiance.
