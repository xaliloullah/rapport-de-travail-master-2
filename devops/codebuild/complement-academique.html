Complément académique — AWS CodeBuild

Intégration continue, automatisation des builds et traçabilité.

1. Problématique

La compilation et les tests manuels produisent des résultats variables et ralentissent la livraison. CodeBuild permet d'exécuter ces opérations dans un environnement défini et reproductible.

2. Pipeline logique

Source → Build → Tests → Artefacts → Étape suivante du pipeline.

Le fichier buildspec.yml décrit les phases et les commandes. Les journaux constituent une preuve d'exécution utile au diagnostic et à l'audit.

3. Qualité

Un build réussi ne signifie pas nécessairement que le logiciel est correct. Il faut distinguer compilation, tests unitaires, tests d'intégration, analyse statique et contrôles de sécurité. Les critères d'acceptation doivent être explicitement définis.

4. Sécurité IAM

  • Limiter le rôle de service aux actions nécessaires.
  • Éviter les secrets en clair dans le buildspec.
  • Contrôler les artefacts produits.
  • Tracer les exécutions et les modifications de configuration.
