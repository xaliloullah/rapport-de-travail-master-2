1. Objectif

Ce guide explique comment :

  • Créer un compte AWS (offre Free Tier si disponible).
  • Comprendre le service EC2 et ses composants clés.
  • Déployer une instance Windows Server 2022 sur EC2 et s’y connecter via RDP.
  • Appliquer les bonnes pratiques de sécurité et de gestion.

2. Création d'un compte AWS (Free Tier)

  1. Aller sur la page d'accueil AWS.
  2. Remplir les informations du compte : e-mail, mot de passe, nom du compte.
  3. Vérification de l’identité via SMS ou appel téléphonique.
  4. Choisir le plan de support : Basic (gratuit) pour débuter.
  5. Saisir les informations de contact (nom, adresse, téléphone).
Remarques importantes :
AWS exige une carte bancaire valide même pour le Free Tier. Activez l’authentification multifacteur (MFA) pour plus de sécurité.

3. Qu'est-ce qu'EC2 ?

EC2 (Elastic Compute Cloud) est un service IaaS qui permet de créer des machines virtuelles dans le cloud.

  • Types d’instances : optimisées CPU, mémoire, stockage ou GPU.
  • AMIs : images préconfigurées Windows ou Linux.
  • Key Pair : clé publique/privée pour récupérer le mot de passe Windows ou SSH sur Linux.
  • Security Groups : filtres réseau pour sécuriser l’accès aux instances (ex. port RDP 3389).

4. Création d'une instance EC2 Windows Server 2022 — procédure détaillée

4.1 Accéder au service EC2

Taper EC2 dans la barre de recherche AWS et accéder au service.

4.2 Lancer la création de l'instance

  1. Cliquer sur Launch Instance.
  2. Choisir l’AMI Windows Server 2022.
  3. Choisir le type d’instance (exemple : t2.micro pour Free Tier).
  4. Configurer réseau, stockage EBS et tags (Name).
  5. Créer ou sélectionner une Key Pair (.pem) et la conserver en lieu sûr.
  6. Configurer le Security Group : autoriser RDP (3389) depuis votre IP.
  7. Lancer l’instance.
  8. Vérifier l’état initial dans la console.
Astuce : Ne jamais autoriser RDP à 0.0.0.0/0 en production.

5. Connexion RDP à l'instance Windows

5.1 Obtenir le mot de passe Administrateur

Sélectionner l’instance → Connect → RDP → Get Windows Password et décrypter avec la clé .pem.

5.2 Télécharger le fichier RDP

Ouvrir le fichier .rdp et saisir le mot de passe Administrateur.

5.3 Confirmation et bureau Windows

Après authentification, vous accédez au bureau Windows Server 2022.

5.4 Points d'attention

  • Vérifier Security Group, IP publique et NAT/Internet Gateway si la connexion échoue.
  • Assurez-vous d’avoir la bonne clé .pem et que l’instance est en état running.

6. Vérifications, sécurité et bonnes pratiques

  • Activer MFA sur le compte racine.
  • Créer des comptes IAM avec droits minimaux pour usage quotidien.
  • Ne pas ouvrir RDP à tout le monde (0.0.0.0/0).
  • Mettre en place des alertes budgétaires pour éviter des frais inattendus.
  • Automatiser les sauvegardes via snapshots EBS.

7. Checklist imprimable

  • [ ] Compte AWS créé et vérifié
  • [ ] MFA activé
  • [ ] EC2 lancé avec Windows Server 2022
  • [ ] Security Group configuré
  • [ ] Key Pair téléchargée et sécurisée
  • [ ] Connexion RDP testée
  • [ ] Backups et snapshots configurés

8. Annexes : commandes AWS CLI et dépannage

# Lister les instances EC2 aws ec2 describe-instances # Vérifier le statut des instances aws ec2 describe-instance-status # Créer un snapshot EBS aws ec2 create-snapshot --volume-id vol-xxxxxxxx --description "Snapshot backup"
Ces commandes peuvent être utilisées pour vérifier, sauvegarder ou dépanner votre instance.

9. Conclusion

Ce guide montre comment :

  • Créer un compte AWS et sécuriser l’accès.
  • Déployer une instance Windows Server 2022 sur EC2.
  • Se connecter via RDP en toute sécurité.
  • Mettre en place des bonnes pratiques pour la sécurité et la gestion des coûts.

En suivant ces étapes, vous disposez d’une base solide pour réaliser des environnements de test ou de production sur le cloud AWS.
