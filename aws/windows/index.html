1. Objectifs et contexte

Ce travail pratique présente le déploiement d’un serveur Windows Server dans Amazon EC2, son intégration au réseau AWS et son administration à distance.

  • Créer une instance EC2 Windows à partir d’une AMI officielle.
  • Configurer VPC, subnet, Security Group, clé et stockage EBS.
  • Récupérer le mot de passe Administrator initial.
  • Établir une connexion RDP sécurisée.
  • Vérifier le système, le réseau et le service Remote Desktop.
  • Appliquer les principes de moindre privilège, de réduction de surface d’attaque et de maîtrise des coûts.
Résultat attendu : une instance Windows Server fonctionnelle, accessible uniquement depuis une source d’administration autorisée.

2. Prérequis

  • Compte AWS actif et région sélectionnée.
  • Permissions IAM adaptées.
  • Paire de clés EC2 RSA conservée de manière sécurisée.
  • VPC et subnet adaptés.
  • Client RDP disponible, par exemple mstsc.exe.

4. Installation et configuration

4.1 Créer la paire de clés

  1. EC2 → Key Pairs → Create key pair.
  2. Choisir un nom comme m2-windows-key.
  3. Sélectionner RSA.
  4. Télécharger le fichier privé .pem et ne jamais le publier.

4.2 Security Group

RDP | TCP | 3389 | YOUR_ADMIN_IP/32

Limiter la source à l’adresse IP publique du poste d’administration ou à un réseau privé de confiance.

4.3 Lancer l’instance

  1. Choisir une AMI officielle Microsoft Windows Server.
  2. Sélectionner le type d’instance.
  3. Choisir VPC et subnet.
  4. Associer le Security Group et la paire de clés.
  5. Configurer EBS et le tag Name=Windows-M2-UDB.
  6. Lancer l’instance.

5. Réalisation pratique

5.1 Identifier l’instance

aws ec2 describe-instances \ --filters "Name=tag:Name,Values=Windows-M2-UDB" \ --query 'Reservations[].Instances[].[InstanceId,State.Name,PublicIpAddress,PrivateIpAddress]' \ --output table

5.2 Récupérer le mot de passe Administrator

EC2 → instance → Connect → RDP → Get Password. Charger la clé privée .pem, puis déchiffrer le mot de passe.

5.3 Connexion RDP

  1. Télécharger le fichier RDP.
  2. Ouvrir mstsc.exe.
  3. Utiliser le DNS ou l’IP publique de l’instance.
  4. Saisir le compte Administrator et le mot de passe.

5.4 Première configuration

  • Vérifier le nom de la machine et le réseau.
  • Installer les mises à jour Windows.
  • Changer le mot de passe Administrator initial.
  • Vérifier les services nécessaires.

9. Sécurité et bonnes pratiques

  • Activer MFA sur les identités humaines AWS.
  • Appliquer le moindre privilège IAM.
  • Ne jamais publier la clé .pem.
  • Limiter TCP/3389 aux sources de confiance.
  • Éviter 0.0.0.0/0 pour RDP.
  • Changer le mot de passe Administrator initial.
  • Maintenir Windows Server à jour.
  • Privilégier Systems Manager lorsque possible.
  • Chiffrer et sauvegarder EBS selon les exigences.

11. Conclusion

Ce travail pratique a permis de mettre en œuvre un serveur Windows dans Amazon EC2 en couvrant les dimensions calcul, réseau, stockage, sécurité et accès distant.

La connexion RDP convient au TP, mais une architecture professionnelle doit réduire l’exposition directe du port 3389 et privilégier des mécanismes d’accès privés ou gérés lorsque cela est possible.
