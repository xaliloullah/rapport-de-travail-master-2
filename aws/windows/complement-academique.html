Complément académique — Windows sur AWS EC2

Déploiement, administration distante et sécurisation d'un serveur Windows.

1. Architecture

Une instance Windows EC2 fournit un environnement de calcul administrable à distance. Le chemin d'administration classique associe l'instance, son Security Group, l'accès RDP et les services installés dans le système.

2. Administration PowerShell

PowerShell permet d'automatiser la configuration et de limiter les manipulations répétitives. L'automatisation améliore la traçabilité et réduit les écarts entre environnements.

Get-ComputerInfo
Get-Service
Get-NetIPConfiguration
Get-WindowsFeature

3. IIS et publication

Le rôle IIS transforme l'instance en serveur web Windows. La publication doit être accompagnée d'un contrôle des ports, d'une stratégie de certificats et d'une gestion des journaux.

4. Sécurité RDP

  • Ne pas ouvrir RDP à Internet sans restriction lorsque cela peut être évité.
  • Limiter la source du port 3389 au réseau d'administration.
  • Utiliser des identifiants robustes et une gestion appropriée des comptes.
  • Maintenir Windows et les rôles installés à jour.
  • Surveiller les événements et les tentatives de connexion.

5. Analyse critique

Windows sur EC2 est pertinent lorsque l'application dépend de l'écosystème Microsoft. Le choix doit toutefois intégrer les besoins en licences, l'administration, la sécurité et le coût d'exploitation.
