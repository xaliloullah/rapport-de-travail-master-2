Complément académique — Web Server Linux sur AWS

Déploiement, exposition, supervision et sécurisation d'un service web.

1. Architecture

Le serveur web constitue une couche applicative placée au-dessus du système Linux et de l'infrastructure EC2. L'accès dépend du routage, du Security Group et de la configuration du serveur HTTP.

2. Cycle de publication

Code → déploiement → serveur HTTP → réseau → client.

Une démarche reproductible documente l'image ou l'OS, les paquets installés, les fichiers de configuration, les ports et les commandes de validation.

3. Diagnostic

systemctl status nginx
systemctl status apache2
ss -lntp
curl -I http://localhost
journalctl -u nginx --no-pager

Ces commandes permettent de distinguer un problème de service d'un problème réseau. Un diagnostic méthodique évite de modifier plusieurs paramètres simultanément.

4. HTTPS et exploitation

Un serveur destiné à être accessible publiquement doit généralement utiliser TLS, un nom DNS approprié, des certificats renouvelables et une politique de mises à jour. Les logs d'accès et d'erreurs doivent être conservés selon les besoins du projet.

5. Sécurité

  • Réduire les ports exposés.
  • Appliquer les mises à jour de sécurité.
  • Utiliser des comptes administratifs contrôlés.
  • Protéger les fichiers de configuration sensibles.
  • Prévoir sauvegarde et restauration.
