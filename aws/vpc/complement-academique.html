Complément académique — AWS VPC

Conception réseau, segmentation et contrôle des flux dans AWS.

1. Problématique réseau

Une architecture cloud doit isoler les composants tout en autorisant les communications nécessaires. Le VPC fournit un espace réseau logique dans lequel les sous-réseaux, tables de routage et passerelles structurent les flux.

2. Architecture de référence

Internet → Internet Gateway → sous-réseau public → Load Balancer → sous-réseaux privés → applications/données.

Un sous-réseau public dispose d'une route vers une passerelle Internet. Un sous-réseau privé n'a pas de route directe vers Internet ; une sortie contrôlée peut passer par une NAT Gateway selon le besoin.

3. Routage et filtrage

Les tables de routage déterminent le prochain saut des paquets. Les Security Groups sont stateful et attachés aux interfaces/ressources ; les Network ACLs agissent au niveau du sous-réseau et sont stateless.

aws ec2 describe-vpcs
aws ec2 describe-subnets
aws ec2 describe-route-tables

4. Conception CIDR

Le choix du CIDR doit anticiper l'évolution de l'infrastructure et les éventuelles interconnexions. Des plages qui se chevauchent compliquent les connexions réseau. La planification doit donc être réalisée avant le déploiement.

5. Analyse critique et sécurité

Un réseau correctement segmenté réduit le périmètre d'exposition mais ne remplace pas l'authentification des applications. Il faut combiner segmentation, chiffrement, contrôle des ports, journalisation et principe du moindre privilège.
