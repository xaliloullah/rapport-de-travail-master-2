Complément académique — AWS CLI sur Ubuntu

Administration d'une instance Linux et automatisation des opérations AWS.

1. Architecture et rôle

Une instance Ubuntu dans EC2 associe calcul, stockage, réseau et identité. L'administration combine l'accès au système Linux et l'API AWS. L'AWS CLI constitue une interface d'automatisation particulièrement utile pour rendre les opérations répétables.

2. Identité de l'instance

Pour un usage professionnel, il est préférable d'associer un rôle IAM à l'instance plutôt que de stocker des clés permanentes sur le serveur. Cette approche réduit l'exposition des secrets et permet de modifier les permissions côté IAM.

aws sts get-caller-identity
aws ec2 describe-instances --query 'Reservations[].Instances[].InstanceId'

3. Administration Linux

La maintenance doit inclure les mises à jour, la gestion des utilisateurs, les permissions, les services, les journaux et la surveillance des ressources. Les commandes exécutées doivent être documentées afin de garantir la reproductibilité de l'expérience.

uname -a
lsb_release -a
systemctl --type=service --state=running
journalctl -p warning -b

4. Sécurité

  • Restreindre SSH au strict nécessaire.
  • Utiliser des clés ou un mécanisme d'accès sécurisé plutôt qu'un mot de passe faible.
  • Mettre le système à jour.
  • Éviter d'exécuter les services applicatifs avec root.
  • Surveiller les logs et les ressources.

5. Analyse critique

L'intérêt de l'AWS CLI ne réside pas uniquement dans le remplacement de la console graphique. Elle permet surtout de standardiser les opérations, de les intégrer dans des scripts et de préparer une démarche Infrastructure as Code.
