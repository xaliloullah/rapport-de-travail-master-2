1. Introduction

Nous commençons tout d’abord par présenter le contexte de ce rapport. L’objectif est de guider pas à pas l’utilisateur pour lancer une instance Ubuntu Server 24.04 LTS sur AWS EC2, s’y connecter via SSH ou EC2 Instance Connect, installer et configurer l’AWS CLI, et préparer un environnement de test ou de développement sécurisé et fonctionnel.

2. Qu'est-ce qu'une instance Ubuntu ?

Une instance Ubuntu sur AWS est une machine virtuelle basée sur une Amazon Machine Image (AMI) Ubuntu. Elle fonctionne comme une machine physique distante : nous pouvons y installer des paquets, exécuter des applications, configurer des services et y accéder via SSH ou EC2 Instance Connect.

2.1 Qu'est-ce que EC2 ?

Amazon EC2 (Elastic Compute Cloud) est le service de calcul d’AWS permettant de lancer et gérer des instances virtuelles. EC2 fournit :

  • Différents types d’instances selon les besoins CPU/mémoire.
  • Des AMIs pour déployer rapidement des systèmes d’exploitation.
  • Volumes EBS pour le stockage persistant.
  • Security Groups pour gérer l’accès réseau.
  • Key Pairs pour sécuriser les connexions SSH.

4. Pré-requis

Avant de commencer, assurez-vous d’avoir :

  • Un compte AWS actif (MFA recommandé).
  • Des permissions IAM pour lancer des instances EC2 et créer des Key Pairs.
  • Une clé privée (.pem) téléchargée et stockée en sécurité.
  • Accès Internet ou VPN, et les ports SSH (22) ouverts dans le Security Group.

5.1 Création d'une instance EC2 Ubuntu

Nous identifions maintenant l’utilisateur qui va lancer l’instance. Nous commençons par accéder à la console AWS → EC2 et suivre les étapes :

  1. Lancer l’assistant "Launch Instances".
  2. Choisir l’AMI : Ubuntu Server 24.04 LTS.
  3. Choisir le type d’instance : par exemple t3.micro (Free Tier éligible).
  4. Configurer le stockage et ajouter un tag Name : Ubuntu_M2_UDB_2025.
  5. Créer ou sélectionner une Key Pair RSA pour SSH.
  6. Configurer le Security Group :
    • Autoriser SSH (port 22) depuis votre IP.
    • Autoriser HTTP (port 80) si vous souhaitez héberger un site.
  7. Lancer l’instance et vérifier dans la liste des instances.

5.2 Connexion à l'instance Ubuntu

Nous pouvons maintenant nous connecter à l’instance :

Méthode 1 — EC2 Instance Connect
  1. Dans la console EC2, sélectionner l’instance → Connect → EC2 Instance Connect.
  2. Cliquer sur Connect pour ouvrir le terminal dans le navigateur.
Méthode 2 — SSH avec la clé privée (.pem)

Sur Linux/Mac :

chmod 400 mykey.pem ssh -i mykey.pem ubuntu@

Sur Windows : utiliser PuTTY (convertir .pem en .ppk) ou PowerShell :

ssh -i C:\chemin\mykey.pem ubuntu@

6. Configuration de l'AWS CLI sur Ubuntu

Nous allons maintenant installer l’AWS CLI v2 sur notre instance :

  1. Mettre à jour le système et installer unzip et curl :
    sudo apt update && sudo apt upgrade -y sudo apt install -y unzip curl
  2. Télécharger et installer AWS CLI :
    curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip" unzip awscliv2.zip sudo ./aws/install
  3. Vérifier l’installation :
    aws --version

7. Conclusion et recommandations

Ce guide a présenté toutes les étapes pour lancer une instance Ubuntu 24.04 LTS sur AWS EC2, se connecter, installer AWS CLI et préparer un environnement sécurisé pour le développement ou le test.

Pour aller plus loin :

  • Activer MFA et utiliser des comptes IAM avec privilèges minimaux.
  • Restreindre SSH aux IP autorisées ou utiliser Systems Manager Session Manager.
  • Créer des snapshots EBS réguliers et planifier des sauvegardes.
  • Préparer la migration vers Terraform/CloudFormation pour l’infrastructure as code.
  • Mettre en place un monitoring CloudWatch et une journalisation centralisée.
